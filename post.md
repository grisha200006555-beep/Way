# Описание бота @gpt52promptbot

🤖 **@gpt52promptbot — твой личный AI-ассистент в Telegram**

Один бот — все топовые нейросети в одном месте. Без VPN, без регистраций на десятке сайтов, без подписок в долларах.

**Что внутри:**
💬 **ChatGPT** — отвечает на вопросы, пишет тексты, код, идеи
✨ **Gemini** (Google) — мощная модель для анализа, перевода и работы с большими текстами
🍌 **Nano Banana Pro** — топовая нейросеть для генерации и редактирования изображений (та самая, про которую говорит весь интернет)

**Что умеет бот:**
— пишет посты, сценарии, статьи и продающие тексты
— решает задачи, объясняет сложное простыми словами
— генерирует картинки по описанию в Nano Banana Pro
— редактирует фото: меняет фон, одежду, стиль
— помогает с учёбой, работой и идеями для контента

**Почему удобно:**
✅ Всё в Telegram — не нужно ничего ставить
✅ Без VPN и зарубежных карт
✅ Переключаешь модели в пару кликов

👉 Запускай: @gpt52promptbot
