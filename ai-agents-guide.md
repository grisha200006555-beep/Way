# Как собрать команду ИИ-агентов как в Myndex Lab

Разбор того, что на видео у Макса Трейси, и пошаговый план — как сделать своё.

## Что вообще на экране

На скриншотах — самописный дашборд "Mission Control" с командой агентов:

- **Kevin** — CTO & Lead Strategist
- **Alice** — Personal Assistant
- **Sam** — DevOps Engineer
- **Leo** — SMM & Content Strategist

Каждый агент имеет статус (Online / Idle / Thinking), общая очередь задач (`TASK QUEUE`), счётчик выполненных, метрики сервера (CPU, RAM, Disk, Uptime) и пиксельная визуализация "офиса", где агенты — спрайты, ходящие между столами.

Это **не продукт с маркета**. Это сборка из трёх кусков:

1. **LLM-агенты** (Claude / GPT / Gemini) через API с инструментами.
2. **Оркестратор** — код, который раздаёт задачи агентам и крутит их в цикле.
3. **Веб-дашборд** для наблюдения и постановки задач.

## Стек, на котором собирается такое

| Слой | Чем делать |
|---|---|
| Мозг агента | Claude Agent SDK / OpenAI Assistants / LangGraph |
| Инструменты | MCP-серверы (файлы, браузер, почта, Telegram, календарь) |
| Оркестрация | Python + Redis-очередь, либо Temporal / Inngest |
| Хранилище | Postgres (задачи, история) + Qdrant/pgvector (память) |
| Бэкенд дашборда | FastAPI / Node + WebSocket для live-статусов |
| Фронт | Next.js + Tailwind, пиксель-офис на Phaser.js или PixiJS |
| Хостинг | VPS (Hetzner CX22 от ~5€/мес) или Fly.io |

## Архитектура в одну схему

```
┌─────────────┐    задачи     ┌──────────────┐
│  Dashboard  │ ────────────► │ Orchestrator │
│  (Next.js)  │ ◄──── статус  │  (Python)    │
└─────────────┘   WebSocket   └──────┬───────┘
                                     │
                  ┌──────────────────┼──────────────────┐
                  ▼                  ▼                  ▼
            ┌──────────┐       ┌──────────┐       ┌──────────┐
            │  Kevin   │       │  Alice   │       │   Sam    │
            │  Claude  │       │  Claude  │       │  Claude  │
            └────┬─────┘       └────┬─────┘       └────┬─────┘
                 │ MCP              │ MCP              │ MCP
                 ▼                  ▼                  ▼
            git, docs          gmail, gcal         docker, ssh
```

Каждый агент — это отдельный процесс/задача, у которого свой системный промпт ("ты — Kevin, CTO…"), свой набор инструментов и своя память.

## Минимальный скелет на Python + Claude Agent SDK

```python
from anthropic import Anthropic
client = Anthropic()

AGENTS = {
    "kevin": {
        "system": "Ты Kevin, CTO. Принимаешь технические решения, "
                  "ставишь задачи команде, ревьюишь код.",
        "tools": ["github", "filesystem", "shell"],
    },
    "alice": {
        "system": "Ты Alice, личный ассистент CEO. Ведёшь календарь, "
                  "пишешь письма, бронируешь, фильтруешь входящие.",
        "tools": ["gmail", "gcal", "telegram"],
    },
    "sam": {
        "system": "Ты Sam, DevOps. Деплоишь, чинишь упавшие сервисы, "
                  "мониторишь алерты.",
        "tools": ["ssh", "docker", "grafana"],
    },
}

def run_agent(name: str, task: str):
    cfg = AGENTS[name]
    resp = client.messages.create(
        model="claude-opus-4-7",
        max_tokens=4096,
        system=cfg["system"],
        tools=load_mcp_tools(cfg["tools"]),
        messages=[{"role": "user", "content": task}],
    )
    return resp
```

Дальше — цикл: получили задачу → выбрали агента → крутим до `stop_reason == "end_turn"` → пишем результат в БД → шлём в WebSocket-дашборд.

## Что даёт ощущение "они живые 24/7"

1. **Демон, который никогда не спит.** Systemd-юнит на VPS, оркестратор всегда запущен.
2. **Триггеры извне** — не только кнопка "новая задача" в UI, но и:
   - cron ("каждое утро Alice присылает дайджест"),
   - webhook от Gmail/Telegram ("пришло письмо → Alice разбирает"),
   - алерт от Grafana ("сервис упал → Sam идёт чинить").
3. **Память между сессиями** — каждый агент пишет итоги в свой "журнал" (vector store), и в следующий запуск тянет релевантное в контекст.
4. **Inter-agent messaging** — Kevin может поставить задачу Sam через ту же очередь. Это даёт эффект "команды".

## Пиксельный офис — это бантик, но классный

В видео визуализация на спрайтах. Делается за вечер:
- **Phaser.js** или **PixiJS** на фронте.
- Спрайты с itch.io ("LimeZu Modern Interiors" — частый выбор).
- Позиция персонажа = статус агента: idle → сидит за столом, thinking → печатает, working → идёт к доске.
- Состояние тянется из того же WebSocket, что и текстовый статус.

## С чего реально начать (5 шагов, выходные)

1. **Один агент, одна задача.** Claude API + 1 системный промпт + 1 MCP (например, файлы). Пусть он генерит отчёт раз в день по cron.
2. **Добавь второго с другой ролью.** Уже почувствуешь, как ими дирижировать.
3. **Сделай очередь задач в Postgres** (`tasks` с полями `agent`, `prompt`, `status`, `result`).
4. **Накинь простой UI** — список задач + кнопка "новая" + статусы. Без пикселей, чисто Tailwind.
5. **Подключи внешний триггер** — Telegram-бот, который шлёт задачи в очередь. С этого момента "оно работает само".

После этого пиксельный офис, метрики сервера и красивые карточки — это уже косметика на 2-3 вечера.

## Подводные камни

- **Деньги.** 4 агента, гоняющие Opus в цикле = легко $20-50/день. Для фоновых задач берите Haiku/Sonnet, Opus — только для "Kevin".
- **Бесконечные циклы.** Лимит итераций на задачу и таймаут — обязательно, иначе агент уйдёт в `while True` на тулзах.
- **Доступы.** Если даёте `shell` или `ssh` — обязательно sandbox (Docker, отдельный юзер, whitelisted команды). Иначе один креативный промпт-инжект из письма — и `rm -rf`.
- **Память не безразмерная.** Сжимайте историю (summary каждые N сообщений), иначе контекст распухнет и счёт за токены тоже.

## Готовые куски, чтобы не писать с нуля

- **Claude Agent SDK** — даёт цикл агента и tool use из коробки.
- **MCP-серверы** — github, gmail, slack, postgres, browser уже написаны, ставятся одной строкой.
- **LangGraph** — если нужен граф взаимодействия агентов (Kevin → делегирует → Sam).
- **CrewAI / AutoGen** — высокоуровневые фреймворки "команда агентов", если не хочется писать оркестратор руками.

---

Главная мысль: на видео — не магия и не отдельный продукт. Это **связка из API + очереди + дашборда**, которую один человек собирает за 2-3 недели вечерами. Самое долгое — не агенты, а интеграции (почта, календарь, деплой) и UI.
